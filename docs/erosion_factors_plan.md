# Plan: "coastal erosion factors" (field observation and secondary data)  [DRAFT – FOR STUDENT REVIEW]

*The manuscript promises that "coastal erosion factors are assessed to explain shoreline behavior" (Conceptual Framework p. 5) and that field observations and a checklist were used (Scope p. 7; Reliability p. 46), but no factor data exist in the files. This template lets the group do it quickly and honestly. The GIS result says **where and how fast** the shoreline moved; the factors table is a **descriptive overlay**, not proof of cause. Never write "caused by" unless a source says so.*
